# Automation smoke test

This release records a one-search UI-only smoke test of the collector on the already retained Barnsley to Birmingham New Street pilot route. It is not a complete 10:00–14:00 comparison, has no expanded Journey Details capture, and is not a new route observation or canonical input.

The collection queue covers the full 83-location screen. It is blocked until each origin station has a reviewed mapping; the collector itself captures browser-visible form and results evidence only. A reviewer must choose an itinerary, retain details, transcribe displayed values and run the offline preparer.
