# Repository orientation

This project compares broad UK locations for buying or renting a one-bedroom flat.
The initial list contains 63 places in England and Wales. Keep all locations in the
screen; do not progress to neighbourhoods, buildings or listing samples unless the
user explicitly changes the scope. Do not inherit material from
`data/archive/UK flats (attempt 2)/` unless the user asks for it.

## Structure and workflow

- `data/archive/UK flats (attempt 2)/`: immutable historical handover, including workbook and UI.
- `data/archive/`: scripted CSV exports of that handover; not current findings.
- `data/inputs/`: editable canonical CSV tables for this attempt.
- `data/derived/` and `web/data.js`: generated by `python3 scripts/build.py`.
- `scripts/extract_legacy.py`: deterministic offline archive extraction; `--initialize`
  seeds inputs once and refuses to overwrite existing input CSVs.
- `web/`: current broad comparison, opened directly via `web/index.html`.
- `docs/`: methodology, provenance, schema and outstanding work.

Read README.md and docs/methodology.md before changing data or presentation.
Use Python 3 standard library only for this pipeline. Run `python3 scripts/build.py`
and `python3 -m unittest discover -s tests` after pipeline changes. Commit inputs,
scripts and generated outputs together. Never hand-edit generated files.

## Evidence rules

Retain source URLs, original recorded retrieval dates, periods, geography, sample
counts, confidence and reasons. Imported claims are unverified legacy evidence,
not newly retrieved facts. Missing data stay blank, never zero. Do not invent
missing dates, geography codes, source observations or collection procedures.
Buying values are achieved all-size flat proxies, not one-bedroom estimates.
Rent values are modelled one-bedroom LA means, not asking rents or medians.
Portal counts are snapshots; transport and environment assessments are coarse.

The crime replacement is complete for the current screen: reviewed ONS CSP
violence-against-the-person and sexual-offence rates are displayed separately for
all 63 locations. Preserve historical counts only in the archive; do not use them
as comparable safety measures. Police.uk ASB remains research-only until a dated
archive passes coverage and geography review. Keep data acquisition,
transformation and presentation separate. New locations must flow through the
same CSV/build process without hard-coded row counts.
